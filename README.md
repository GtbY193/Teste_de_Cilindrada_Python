Calculadora de Cilindrada

Projeto desenvolvido em Python para calcular a cilindrada de motores a combustão.

Funcionalidades
Calcula a cilindrada total do motor em cm³.
Converte o resultado para litros.
Permite informar o diâmetro do cilindro, o curso do pistão e a quantidade de cilindros.
Fórmula utilizada

V = (π × D² × C × N) / 4000

Onde:

D = diâmetro do cilindro em milímetros
C = curso do pistão em milímetros
N = número de cilindros
Tecnologias
Python 3
Biblioteca padrão math
Como executar

Execute o arquivo main.py com Python 3 instalado no computador.

Exemplo

Para um motor com diâmetro de 80 mm, curso de 75 mm e 4 cilindros, a cilindrada é de aproximadamente 1507,96 cm³, ou 1,508 litro.
